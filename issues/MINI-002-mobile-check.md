# MINI-002 – Drei Prüfungen für mobile Bedienbarkeit

**Zeitbedarf:** ca. 10–15 Minuten · **Label-Vorschlag:** `good first issue`, `accessibility`.

**Aufgabe:** Formuliere drei überprüfbare Prüfpunkte für einen KI-Chat auf einem Smartphone: (a) Eingabefeld bei 320 px Breite, (b) Senden mit Tastatur/Screenreader, (c) verständliche Fehlermeldung bei nicht erreichbarer KI.

**Abnahme:** Für jeden Fall **Schritte**, **erwartetes Verhalten**, **Hinweis auf benötigte Testumgebung**. Du musst keine interne App installieren oder private Nutzerdaten fotografieren.
