# Sicherheit

**Keine privaten Systemdaten oder Schwachstellen öffentlich posten.** Geheimnisse, SSH-Schlüssel, Tokens, Rechnungen, personenbezogene Dokumente, private URLs und echte Schülerdaten dürfen nicht in ein Issue, eine E-Mail an die Community oder eine öffentliche Demonstration gelangen.

Vertrauliche Sicherheitsmeldungen zunächst ausschließlich an `marco@marco-ki.de` mit Betreff `Vertraulicher Sicherheitshinweis MARCO KI`. Keine Scans, Lasttests, Exploit-Versuche oder Zugriffe auf interne MASTER-Endpunkte ohne separate ausdrückliche Autorisierung. Ein Bug-Bounty-Programm wird nicht angeboten.

Beiträge werden vor Veröffentlichung unabhängig geprüft. Ein erfolgreicher privater Test ist **keine** Freigabe für produktiven Code.
